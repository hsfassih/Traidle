5. NUMERIC DEFINITIONS, REGISTRY, CONSTANTS
   Expression grammar = contract section 6 (single-line pure expression; candle fields open high low close
   volume quote_volume taker_buy_volume taker_buy_quote_volume body range upper_wick lower_wick ny_minute ny_dow;
   the 14 stored indicators; engine collections swing_high[k] fvg bullish_fvg[k] order_block ... with the wire
   fields listed in the catalog; x[-n] history; @bias_tf|@setup_tf|@entry_tf|@15m scopes; arithmetic,
   comparison, AND/OR/NOT, abs min max avg highest lowest count any all; K_* constants; booleans are 1/0 in
   arithmetic; unavailable data only as external.* (linter treats it as not available => tier C)).
   Units rule: ATR(14) multiples, percent of price, fractions of a leg/range, R-multiples, candle counts (state
   the timeframe), NY minute-of-day, candle-geometry ratios. FORBIDDEN in numeric_definition/structured: pips,
   points, ticks, absolute prices, symbol-specific numbers. Presenter-stated market-specific numbers ("20-30
   pips", "8-10 points on ES") stay verbatim in text/quote with a note that they are market-specific, and the
   machine rule is structural (e.g. beyond the sweep extreme + K_STOP_BUFFER_ATR).
   Presenter-stated numbers (R:R, candle counts, Fibonacci levels, percentages) are used EXACTLY as stated.
   A number the presenter did not state is allowed ONLY as a registered tunable K_* constant with rationale.
   Qualitative -> numeric proxies only when defensible: displacement = engine constant K_DISPLACEMENT_*;
   consolidation = N-candle range <= K x ATR; shallow retracement = depth <= K x leg; respected FVG = no body
   close through the far edge; "close to the target" = remaining distance <= fraction of the leg. Mark them
   definition_source "inferred". Truly discretionary ("obvious within 10 seconds") => numeric_definition null,
   not computable, one-line reason.
   Prefer the engine's own definition when it matches the presenter's meaning; otherwise create a custom signal
   that states exactly what the presenter means. NEVER label a custom concept as engine-supported.
   Engine facts you must respect (verified in code): no repainting (a condition is knowable only when its
   confirming candle closes); liquidity_sweep_* fires on ANY breach (wick or body), so a pure sweep = sweep AND
   close back on the original side (registry: pure_sweep); engine `bias` is BOS/CHoCH structure bias, not the
   presenter's draw-on-liquidity bias; engine premium_discount is the latest swing pair, not a dealing range;
   OB definition is stricter than presenters'; FVG needs a displacement candle, mitigated = price reaches CE,
   filled/inverted = body close through the far edge; pdh/pdl valid on <= 1h only; kill zones are fixed

   candles (registry midnight_open, weekly_open, london_open_price, asian_range_*).
